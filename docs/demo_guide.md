# Demo guide

1. Start the backend and frontend using the README commands.
2. Open Diagnose and upload a clear leaf image.
3. Point out the prominent demo-mode warning before discussing the placeholder class.
4. Compare the original, preprocessed, leaf-mask, and experimental lesion-mask artifacts.
5. Explain that affected area is a color heuristic and not Grad-CAM.
6. Open Live Camera, grant permission, and show measured processing latency.
7. Use Capture & Full Diagnosis for the full pipeline.
8. Open Research and state that results appear only after real experiments produce files.
